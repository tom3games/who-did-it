# 犯人は誰だ？

屋敷を歩いて証拠を探し、仲間の中にいる犯人を当てる推理ゲーム。友達にリンクを送るだけで、スマホのブラウザから遊べる。

- 人数: 4〜8人
- 1プレイ: 最長 4分（役割確認15秒 → 探索120秒 → 推理75秒 → 投票30秒）。全員が「終える」を押せば早く進む
- ポート: 8102

## 遊び方

1. ホストが部屋を作り、招待URL（/r/コード）を送る。4人そろったらシナリオを選んでスタート
2. **役割の確認**: 自分の役割と、自分だけが知っている情報を読む
3. **探索**: 移動パッド（PCは矢印キー / WASD）で屋敷を歩き、家具に近づいて「調べる」（PCは E かスペース）。見つけた証拠は自分の手帳に入る。手帳から「掲示板に貼る」と全員に見える
4. **推理**: 掲示板・手帳・人物の一覧を見ながら話し合う（会話は通話やその場で）
5. **投票**: 犯人だと思う人に1票。犯人が単独で最多票なら事件解決、外れか同票なら犯人の逃げ切り
6. **結果**: 犯人・票数・犯人がした細工・本物の手がかりを公開。ホストが「もう一回」で同じメンバーで再戦

### 推理の仕組み

- 人物にはそれぞれ公開の特徴が3つある（利き手・靴・香り）
- 屋敷には犯人の特徴を1つずつ示す本物の手がかりが3つ、別々の部屋に隠れている。3つそろうと犯人は1人に絞れる（1つだけでは絞れないように配る）
- 犯人は痕跡を1つ**隠す**、偽の証拠を1つ**偽装**できる。どちらも周りからは「調べている」のと同じ見た目で、3つの行動は同じ時間がかかる
- 偽装すると、同じ特徴について掲示板の証拠が食い違う。画面は「食い違い」を出すので、どれが偽物かを話し合う
- 自分の部屋にいる人しか見えない（他の部屋は暗い）。誰がどこで何を調べていたかも推理の材料になる

### 役割

| 役割 | 人数 | できること（本人にだけ届く情報） |
|---|---|---|
| 犯人 | 1 | 自分の痕跡の場所が分かる（地図に赤い印）。隠す1回・偽装1回 |
| 探偵 | 1 | 検視で犯人の特徴を1つ最初から知っている（犯人にも消せない）。調べるのが速い |
| 鑑識 | 1 | 自分で調べた証拠の本物/偽物が分かる。掲示板の証拠を2回まで鑑定できる |
| 目撃者 | 5人以上で1 | 犯人ではない人を1人知っている |
| 住人 | 残り | 特別な力なし |

秘密の情報（役割・痕跡の場所・鑑定結果・検視・目撃）はサーバーが `view(プレイヤー)` でその本人の分だけを送る。他人の通信には入らない（テストで確認）。

## 起動

```
npm install
npm start
```

ブラウザで http://localhost:8102 を開く。同じWi-Fiのスマホからは http://<このPCのIP>:8102 。

## テスト

```
npm test            # 単体＋統合テスト 39件
node tools/e2e.mjs  # chromium と webkit で4人つないで最後まで遊ぶ。スクショは tools/shots/
node tools/make-og.mjs  # public/og.png（1200x630）を作り直す
```

e2e は 390x844 / 360x640 / 844x390 の3サイズで各画面を撮り、画面からのはみ出し・ページの縦スクロール・小さすぎるボタン・コンソールエラーを数値で確かめる。

## シナリオを足す

1. `public/scenarios/mansion.mjs` をコピーして新しいファイルを作る（地図・部屋・家具・人物の肩書き・特徴と手がかりの文）
2. `public/scenarios/index.mjs` の `SCENARIOS` に1行足す

犯人と手がかりの置き場所は毎回サーバーがくじで決めるので、シナリオのファイルは画面に配ってよい（答えは入っていない）。ロビーでホストがシナリオを選べる。

## デプロイ

このフォルダ1つが1つのサービス。

- Render: `render.yaml`（Blueprint）。無料プランは15分アクセスが無いと眠る
- Fly.io / Cloud Run など: `Dockerfile`（PORT=8080）

どちらも契約が必要なのでまだ公開していない。og:image は来たホスト名から絶対URLにして返す（`x-forwarded-proto` / `x-forwarded-host` を見る）。

## 構成

```
lib/game.mjs                ルール（役割・証拠・移動・投票・勝敗）。状態はここだけが持つ
lib/rooms.mjs               ルーム・再接続・ホスト交代（雛形の共通部分）
public/scenarios/*.mjs      シナリオのデータ（サーバーと画面の両方が読む）
public/game-view.js         ゲーム中の画面（Canvas の地図と、手帳・掲示板・人物・投票）
public/app.js               ホーム→ロビー（シナリオ選択）→ゲーム→結果
```

移動はサーバーの固定 tick（12回/秒）で進む。画面は届いた位置を補間して描くだけ。

## 今後の改善

- 足あと・物音など「行動の痕跡」をもう1種類足して、犯人の隠す/偽装をもっと推理の材料にする
- 人数が多いとき（7〜8人）の手がかりの数や犯人の細工回数の調整
- 話し合いの時間を部屋の設定で変えられるようにする
- 通信量: 8人で1人あたり約16KB/秒。位置が変わった人だけ送るなどでさらに減らせる
