# 犯人は誰だ？

屋敷を3Dで歩いて証拠を探し、仲間の中にいる犯人を当てる推理ゲーム。友達にリンクを送るだけで、スマホのブラウザから遊べる。

- 人数: 4〜8人
- 1プレイ: 最長 5分弱（役割確認15秒 → 探索130〜160秒 → 推理75秒 → 投票30秒）。全員が「終える」を押せば早く進む
- ポート: 8102

画面は 3D（Three.js r185 を `public/vendor/` に同梱。CDN に頼らない）。斜め見下ろしの視点で、自分のキャラクターを追いかける。WebGL が使えない端末では、真上から見た 2D の地図に自動で戻る（`?2d` を付けると 2D で確かめられる）。

## 遊び方

1. ホストが部屋を作り、招待URL（/r/コード）を送る。4人そろったら事件（シナリオ）を左右の矢印で選んでスタート。ホストの選択は参加者の画面にも出る
2. **役割の確認**: 役割カードがめくれて、自分の役割と自分だけが知っている情報が出る。上には事件の現場（遺体とチョークの線）
3. **探索**: 左下のスティック（PC は矢印キー / WASD）で歩き、家具の「?」に近づいて右下の「調べる」（PC は E かスペース）。床や家具を押すと、そこまで歩いて行って調べる。見つけた証拠は手帳に入り、手帳から「掲示板に貼る」と全員に見える
4. **推理**: 上に全員が面通しのように並ぶ。掲示板・手帳・人物・記録（雷の瞬間の居場所）を見ながら話し合う（会話は通話やその場で）
5. **投票**: 犯人だと思う人に1票。犯人が単独で最多票なら事件解決、外れか同票なら犯人の逃げ切り
6. **結果**: 号外の新聞。見出し・犯人の顔写真に「逮捕」か「迷宮入り」のハンコ、誤認逮捕なら「冤罪」。全員に称号、投票の内訳、犯人がした細工、本物の手がかり、この端末の通算記録。ホストが「もう一回」で同じメンバーで再戦

### 探索は3幕でだんだん難しくなる

探索の長さに対する割合で、全員に同じできごとが起きる（`lib/game.mjs` の `EVENTS`）。画面左上の帯に「第何幕」と「次のできごとまで何秒」が出る。

| いつ | できごと | 効果 |
|---|---|---|
| 22% | 雷 | 光った瞬間の全員の居場所が「記録」に残る（推理の材料） |
| 22% | 停電（第2幕） | 部屋の明かりが消え、手元のランタンだけ。同じ部屋でも 2.6 マスより離れた人は見えない。調べる・隠す・偽装が 1.5 倍遅い |
| 42% | 明かりが戻る | |
| 52% | 夜が深まる（第3幕） | 犯人の偽装が1回増える |
| 64% | 嵐で扉が閉まる | 誰も近くにいない扉が1つ閉じて通れない（閉じ込められることもある） |
| 82% | 2回目の雷 | もう一度、全員の居場所が記録される |
| 86% | 扉が開く | |

BGM は幕が進むほど速く・音が増える。

### 事件（シナリオ）

| | 難しさ | 部屋 | 家具 | 手がかり | 探索 |
|---|---|---|---|---|---|
| 霧ヶ丘の小さな屋敷 | 1 | 7 | 15 | 3（利き手・靴・香り） | 130秒 |
| 豪華客船オーロラ号 | 2 | 8 | 19 | 3 | 145秒 |
| 雪山の山荘 | 3 | 9 | 20 | 4（＋手袋） | 160秒 |

場所ごとに外の景色（屋敷は庭木と街灯と雨、船は海と船体と煙突、山荘は針葉樹と雪山と雪）、壁紙、床の張り方、BGM、新聞の名前が変わる。

### 推理の仕組み

- 人物にはそれぞれ公開の特徴がある（利き手・靴・香り、山荘は手袋も）。靴の特徴は 3D のキャラクターの靴の色にも出る
- 犯人の特徴を1つずつ示す本物の手がかりが、別々の部屋に隠れている。全部そろうと犯人は1人に絞れる（1つだけでは絞れないように配る）
- 犯人は痕跡を1つ**隠す**、偽の証拠を**偽装**できる（夜が深まるともう1回）。どれも周りからは「調べている」のと同じ見た目で、同じ時間がかかる
- 偽装すると、同じ特徴について掲示板の証拠が食い違う。画面は「食い違い」を出すので、どれが偽物かを話し合う
- 自分の部屋にいる人しか見えない（他の部屋は暗い）。誰がどこで何を調べていたかも推理の材料になる

### 役割

| 役割 | 人数 | できること（本人にだけ届く情報） |
|---|---|---|
| 犯人 | 1 | 自分の痕跡の場所が分かる（家具の上に赤い「!」）。隠す1回・偽装1回（夜が深まると＋1） |
| 探偵 | 1 | 検視で犯人の特徴を1つ最初から知っている（犯人にも消せない）。調べるのが速い |
| 鑑識 | 1 | 自分で調べた証拠の本物/偽物が分かる。掲示板の証拠を2回まで鑑定できる（判子が押される） |
| 目撃者 | 5人以上で1 | 犯人ではない人を1人知っている |
| 住人 | 残り | 特別な力なし |

秘密の情報（役割・痕跡の場所・鑑定結果・検視・目撃）はサーバーが `view(プレイヤー)` でその本人の分だけを送る。他人の通信には入らない（テストで確認）。画面上の役割ボタンには役割の名前を出さない（横からのぞかれても分からない）。

### 称号と記録

結果で全員に称号が1つ付く（名探偵・鋭い勘・濡れ衣・冤罪づくり・調べ魔・情報屋・まんまと偽物・置物・ただの客、犯人は 満場一致でお縄・お縄・完全犯罪・逃げ切り・夜逃げ の全14種）。この端末の通算（回数・勝ち・最高連勝・犯人での勝ち・集めた称号）は localStorage に残り、ホームにも出る。初めて取った称号には「初」の印。

## 3D の見た目（`public/view3d.js`）

- 地図の1マス = 1 単位。マス (x, y) は 3D の (x, 0, y)。サーバーの 2D の移動をそのまま立体で見せる
- カメラ: 自分の南（手前）の斜め上（俯角46度）から北を見下ろし、自分を追いかける。向きは固定なので「スティックの上 = 画面の奥 = 地図の上」がずっと同じ。自分より手前の壁と扉は低くなり、自分と部屋の中が隠れない。右上の虫めがね（または見取り図を押す、PC は Z）で屋敷ぜんぶを見る引きの視点
- キャラクター: 頭の大きいちびキャラ。帽子と小物は肩書きで変わる（シルクハット・コック帽・麦わら・ベレー帽・ヘルメット・ニット帽など）。服は参加者の色、靴は「靴」の特徴の色。表情は 普通／見つけて笑顔／細工してにやり／何も無くて考える／調べて目をこらす／雷で驚く／停電で不安。立ち止まるとこちらを向き、向こうへ歩くときは後ろ頭が見える
- 自分の部屋は電球色の明かり、他の部屋は暗い。停電中は手元のランタンだけ。雷は画面が白く光る
- 遺体は床に倒れていて、チョークの線で囲まれている（目はバツで、こわくない程度に）
- 推理と投票では、赤い幕の前に全員が面通しのように並ぶ。投票した人は足もとに赤い輪
- トゥーン（3段の陰影）と輪郭線。壁は InstancedMesh
- 重さ対策: 画素比の上限（画質 高2 / 中1.5 / 低1）、影は月の光1灯（低では影なし）、雨と雪は中以上だけ。fps が 40 を切ると画質を1段下げる（スマホは中から始める）
- 名前の札は HTML を 3D の頭の上に重ねる。8人の面通しでは札を1人おきに足もとへ出して重ならないようにする

## 画面

- ホーム: 題字のロゴ（SVG）、嵐の夜の屋敷の影絵と月と雨、捜査ファイルのカード、遊び方（絵で4つ）
- ボタンは押し込める立体（下の影が縮む）。アイコンは全部自前の SVG で、絵文字は使わない
- ロビー: 参加者の似顔絵、事件のカード（見取り図・難しさの星・あらすじ・部屋と手がかりの数）
- ゲーム中: 上に時計（残り時間の帯つき）・役割・引きの視点・音、その下に幕の帯と見取り図。下にスティックと「調べる」、タブ（手帳・掲示板・人物・終える）
- 縦持ちも横持ちも、どの画面も上下にスクロールせず一画面に収まる。ピンチ・ダブルタップ・Ctrl+ホイールの拡大は止めている
- 起動に失敗したら原因を画面に出す（素の script で `error` を拾い、エラーが出たら8秒、出なくても20秒たって起動していなければ表示。後から起動できたら消す）

## 起動

```
npm install
npm start
```

ブラウザで http://localhost:8102 を開く。同じWi-Fiのスマホからは http://<このPCのIP>:8102 。

## テスト

```
npm test                     # ルール・部屋・通信の単体/統合テスト（48件）
npx playwright install chromium webkit   # 初回だけ
node tools/e2e.mjs           # 実ブラウザで最後まで遊ぶ（下）。ONLY=chromium / ONLY=webkit / SKIP8=1 で絞れる
node tools/fps.mjs           # GPU を使う headless Chromium で、スマホ相当（390x844・画素比3）と横持ちの fps を3つの事件ぶん
node tools/shot-ui.mjs       # ホーム・遊び方・ロビーを4サイズで撮る
node tools/shot-game.mjs [mansion|ship|lodge]  # 役割・探索・手帳・人物・停電・嵐・引きの視点・推理・投票・結果を4サイズで撮る
node tools/make-og.mjs       # public/og.png（1200x630）を作り直す（4人が廊下に並ぶ 3D の画面にロゴを重ねる）
```

`tools/e2e.mjs` は chromium（屋敷）と webkit（山荘）で4人つないで、作成→招待URLで参加→事件の選択（参加者にも見える）→開始→役割（役割ボタンに名前が出ない）→探索（調べる・家具を押して歩いて調べる・キーボード・スティックの上で奥へ歩く・犯人が隠す/偽装・掲示板に貼る・鑑識の鑑定・停電・嵐で扉）→推理→投票→結果（見出し・ハンコ・称号・記録）→再戦 を通す。続けて `?2d` で開き直して 2D に戻ることと、20秒たっても起動エラーの表示が出ないことを見る。最後に webkit で8人（船）を同票の逃げ切りまで遊ぶ。
各画面を 390x844 / 360x640 / 844x390 / 568x320 で撮り、はみ出し・ページの縦スクロール・44px 未満のボタン・ボタンの上に別のものがかぶっていないか・コンソールエラーを数値で確かめる。3D が描けているかは画素の分散で見る。スクショは `tools/shots/`。

## シナリオを足す

1. `public/scenarios/mansion.mjs` をコピーして新しいファイルを作る（地図・部屋・床の張り方・家具・人物の肩書きと見た目・特徴と手がかりの文・難しさ・探索の秒数・見た目のテーマ）
2. `public/scenarios/index.mjs` の `SCENARIOS` に1行足す
3. `npm test` で形（全部の部屋と家具に届く・扉の前に家具が無い・5分を超えない・手がかりで1人に絞れる）を確かめる

犯人と手がかりの置き場所は毎回サーバーがくじで決めるので、シナリオのファイルは画面に配ってよい（答えは入っていない）。家具の 3D の形は `view3d.js` の `furniture()`、場所の景色は `THEMES` と `load()` に足す。

## デプロイ

このフォルダ1つが1つのサービス。WebSocket が使えるホスティングが必要（静的ホスティング不可）。

- Render: `render.yaml`（Blueprint）。無料プランは15分アクセスが無いと眠る
- Fly.io / Cloud Run など: `Dockerfile`（PORT=8080）
- og:image は来たホスト名から絶対URLにして返す（`x-forwarded-proto` / `x-forwarded-host` を見る）
- 文字のファイルは gzip で送る。`/vendor/`（three.js）は1日キャッシュ

いまは手元の Mac から cloudflared のクイックトンネルで公開している（`../publish.sh`。URL は起動のたびに変わり、Mac が起きている間だけつながる）。

## 構成

```
lib/game.mjs                ルール（役割・証拠・移動・できごと・投票・勝敗・称号）。状態はここだけが持つ
lib/rooms.mjs               ルーム・再接続・ホスト交代・ロビーの選択の共有（雛形の共通部分）
public/scenarios/*.mjs      シナリオのデータ（サーバーと画面の両方が読む）
public/view3d.js            3D の描画（屋敷・家具・ちびキャラ・景色・面通し）
public/game-view.js         ゲーム中の画面（3D か 2D、手帳・掲示板・人物・投票、操作）
public/result.js            結果の新聞・称号・この端末の記録
public/art.js               似顔絵・アイコン・ロゴ・見取り図（SVG）
public/sound.js             効果音と BGM（Web Audio。音のファイルなし）
public/app.js               ホーム→ロビー（事件の選択）→ゲーム→結果
```

移動はサーバーの固定 tick（12回/秒）で進む。画面は届いた位置を補間して描くだけ。
